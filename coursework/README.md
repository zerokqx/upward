## 🚀 Быстрый запуск

Сборка полного документа (генерация ODT, конвертация в PDF, валидация номеров страниц TOC) выполняется одной командой:

```bash
# Из корня репозитория:
python3 coursework/build_all.py

# Либо из директории coursework:
cd coursework
./build_all.py
```

### Дополнительные опции:
```bash
# Полная перегенерация векторных и растровых диаграмм (Draw.io -> SVG -> PNG) перед сборкой:
python3 coursework/build_all.py --render-diagrams
```

## 📊 Основные разделы курсовой работы

| Раздел | Стр. в PDF | Описание содержания |
| :--- | :---: | :--- |
| **ТИТУЛЬНЫЙ ЛИСТ** | 1 | Официальный бланк АНО ПОО «КЭПиИТ» без отображаемого номера страницы |
| **СОДЕРЖАНИЕ** | 2 | Оглавление со сквозными номерами страниц и отточиями |
| **ВВЕДЕНИЕ** | 3–5 | Актуальность, цель, объект, предмет, задачи, научная новизна и практическая значимость |
| **ГЛАВА 1** | 6–27 | **Предпроектное исследование**: описание предметной области, анализ аналогов (UptimeRobot, BetterStack, Prometheus), бизнес-процессы в IDEF0 (7 схем Ramus, AS-IS vs TO-BE, потоки ICOM), выбор стека (Rust/Tokio, TimescaleDB, Redis, Axum, NestJS) |
| **ГЛАВА 2** | 28–42 | **Рабочий проект**: архитектура, ER-диаграмма БД, гипертаблицы TimescaleDB, контроллеры и воркеры Uptime, Swagger UI, криптография Ed25519/JWKS, L7-балансировка Nginx, SSRF-защита, отладка и руководство программиста |
| **ЗАКЛЮЧЕНИЕ** | 43–45 | Подведение итогов, оценка соответствия ТЗ, перспективы развития |
| **СПИСОК ИСТОЧНИКОВ** | 46–47 | Нормативно-правовые акты (ГОСТ, ФЗ № 152), техническая и научная литература |
| **ПРИЛОЖЕНИЯ** | 48–50 | **Приложение А**: модуль воркера Tokio; **Приложение Б**: валидатор SSRF; **Приложение В**: DDL миграции TimescaleDB |
