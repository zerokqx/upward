# Entities Layer (FSD)

Слой `entities` (бизнес-сущности) содержит модели данных, типы, API-запросы и базовые элементы UI, относящиеся к предметной области приложения:

- `monitor` — модель мониторинга доступности, статусы проверок.
- `site` — сущность проверяемого ресурса/сайта.
- `user` — данные профиля пользователя и сессии.
- `metric` — собранные метрики ответа и латентности.

Каждая сущность оформляется в виде слайса с сегментами:
- `model/` — типы, схемы валидации, селекторы, хуки/сторы.
- `api/` — функции запросов к бэкенду.
- `ui/` — компоненты карточек, аватаров, статусов сущности.
- `index.ts` — публичный API слайса.
